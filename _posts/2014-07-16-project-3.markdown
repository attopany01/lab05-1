# Intro to Visual Studio Code Lab03: Getting Started  
### Client: Hang Zhao  
**Project Date:** September 26, 2024  
**Category:** Code Editing & Productivity  

---

## **Overview**
In this project, I got to know Visual Studio Code (VSCode), a powerful tool for coding. I focused on:  
- **Interface Navigation:** Learning how to move around and use the editor efficiently.  
- **Code Editing and Debugging:** Writing and fixing code more easily.  
- **Extensions:** Adding tools to improve my workflow.  
- **Git Integration:** Using VSCode to manage code changes with Git.  

> VSCode makes coding smoother and gives you the tools you need to work faster and better.

---

## **Reflection**
This project helped me feel confident using VSCode for coding. I learned how to set it up with tools that make development easier and how to work with Git directly in the editor.  

### Key Skills:
- Editing and debugging code efficiently.  
- Using extensions to add helpful features.  
- Managing code versions without leaving VSCode.
