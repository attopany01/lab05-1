# Intro to GitHub Lab02: Working Together  
### Client: Hang Zhao  
**Project Date:** September 26, 2024  
**Category:** Version Control & Teamwork  

---

## **Overview**
In this project, I learned how to use GitHub for teamwork. I focused on:  
- **Pull and Push:** Sending updates and getting changes from others.  
- **Branches:** Keeping different features or fixes separate.  
- **GitHub Flow:** A simple way to work with a team step-by-step.  

> GitHub makes it easier for everyone to stay on the same page while coding together.

---

## **Reflection**
This project showed me how to use GitHub to work better with others. I learned how to keep things organized, share my work, and review changes clearly.  

### Key Skills:
- Sharing updates without overwriting others’ work.  
- Keeping code clean and organized with branches.  
- Following a process to make teamwork smoother.
