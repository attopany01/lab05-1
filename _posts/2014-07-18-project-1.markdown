# Git Lab01: Introduction to Version Control  
### Client: Hang Zhao  
**Project Date:** September 24, 2024  
**Category:** Version Control Systems  

---

## **Overview**
This project was an introduction to Git, a powerful tool for tracking and managing code changes. I focused on:  
- Setting up Git and configuring user credentials.  
- Creating and managing repositories.  
- Tracking changes with commits.  
- Working with branches to organize development.  
- Merging changes and resolving conflicts.  

> Version control is the foundation of collaboration in software development.

---

## **Reflection**
Through this project, I learned how Git simplifies teamwork and keeps projects organized. Key lessons included the importance of frequent commits, using branches for experimentation, and maintaining clear histories to avoid conflicts.
